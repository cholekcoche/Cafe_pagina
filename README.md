I created a website about coffee. I tried to use many animations and make a cool website with right colors and nice stuff. At the same time I added some JS only for details (not animation).
The main goal of this project is decorative—to create a beautiful website.

For this project I use HTML5, CSS3 and JS.
JS only to program buttons and fix details at some animations.

Good palettes of colors.
Smooth animation.
Animated buttons.
Buttons with JS.
Layouts using Grid and Flex.
3D model view.


To view my website I recommend to open a "live server" to see correctly the animations and 3D models. 
You need a server or an extension "live server".

You have 2 ways to open my project.

Going to https://cholekcoche.github.io/Cafe_pagina/

or

1. Downloading my repository (all)
2. Open it in vs code (or any which support extensions)
3. Make sure that you have "live server" download at your editor.
4. Right-click on index.html → Open with Live Server
5. Enjoy
   Without server or the extension, you should have problems to see my page.
